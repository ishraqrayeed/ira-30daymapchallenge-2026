# Day 7 — Accessibility

## Same city. Quite the journey.

Denver Union Station → Denver International Airport. User-created map supplied
as `day7.png`, published unchanged at the user's request. Route generated with
OpenRouteService, visualized in Kepler.gl, and laid out in PowerPoint in about
10 minutes. The repository plan calls Day 7 “10 minute map”; the supplied title
uses “Accessibility”.

[View the map](map.html)

The image reports 25 miles and 30 minutes driving. These are the creator's route
estimates, not live traffic information. Original route geometry, request date,
boundary dataset, basemap provider, and source-specific terms were not supplied;
the screenshot alone cannot reproduce or independently validate those values.
The original image was visually reviewed and preserved byte for byte.

Tools: [OpenRouteService](https://openrouteservice.org/),
[Kepler.gl](https://kepler.gl/), Microsoft PowerPoint.
