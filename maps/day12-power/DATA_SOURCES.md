# Data sources and interpretation

## Transmission corridors

[U.S. Electric Power Transmission Lines (Archive)](https://www.arcgis.com/home/item.html?id=d4090758322c4d32a4cd002ffaa0aa12), credited to the U.S. Government and hosted by Esri's Federal User Community. [Feature service](https://services2.arcgis.com/FiaPA4ga0iQKduv3/arcgis/rest/services/US_Electric_Power_Transmission_Lines/FeatureServer/0). The item's stated data currency is **September 30, 2024**. Later service edit timestamps do not establish current infrastructure conditions. Retrieved November 11, 2026.

[Argonne's HIFLD metadata](https://gem.anl.gov/tool/layers/transmission_line_hifld/versions/5/metadata.pdf) identifies the underlying transmission dataset as **None (Public Use)**. That metadata documents a December 2022 HIFLD version; it is not evidence that every record in the later service is unchanged. The archive host separately lists the [Esri terms](https://links.esri.com/agol_tou). These host terms are preserved in `data/sources.json`; no Creative Commons license is asserted. [EIA's transmission-data FAQ](https://www.eia.gov/tools/faqs/faq.php?id=567&t=3) provides additional source context.

Python requests all 3,997 intersecting records in longitude/latitude bounds `[-119.8, 32, -110.2, 38.3]`. Only source records marked `IN SERVICE` with known voltage ≥115 kV are retained. Coordinates are projected to EPSG:5070, clipped to the region, simplified by 35 metres, and divided into display segments no longer than 60 km. Pieces shorter than 350 m are omitted. The result contains **1,268 source records and 1,532 display segments**. Original source IDs are retained; no fabricated connections or substations are added. This filtered, generalized map is incomplete infrastructure context, not an engineering network.

Particle routes are 261 selected segments, prioritizing higher voltage, length, and proximity to Hoover. Each route has 256 samples at equal projected distances, stored in normalized Web Mercator for the GPU. The nearest retained line is about 0.55 km from the plant point; the map does not bridge that gap with an invented line.

## Hoover Dam, cities, land and water

Hoover’s marker, halo, and label use the [Bureau of Reclamation Hoover Dam project reference](https://www.usbr.gov/projects/index.php?id=122), longitude/latitude `[-114.7372, 36.0163]`, checked November 11, 2026. The nearby [Reclamation RISE location](https://data.usbr.gov/location/3514) independently gives 36.0163° N, 114.7374° W (WGS84). These are official reference locations, not a surveyed crest. The previous EIA point `[-114.738006, 36.015510]` represents the downstream powerplant, about 114 m away; it remains the camera anchor and preprocessing reference so framing, geometry and reveal timing are unchanged. The native dam source drives all three halo layers, and the label uses the same corrected coordinate. No connection to a transmission junction is drawn.

Worldwide land, regional state boundaries, and lakes—including Lake Mead—use [Natural Earth](https://github.com/nvkelso/natural-earth-vector), 1:50m country/state geometry and 1:10m lake polygons. [Public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/). Source files are named in the preprocessing script. Generalized historical shorelines do **not** represent current reservoir levels. The raw GitHub branch can change; cached inputs preserve this build. Worldwide countries are simplified by 0.055 degrees. Regional water and boundary features are selected by intersection but retain their full geometry, removing the artificial rectangular background edge.

City glows are manually specified representative city-center coordinates in `app.js`: Las Vegas, Los Angeles, Phoenix, Boulder City, Kingman, and Palm Springs. They are contextual symbols, not demand estimates, measured nighttime brightness, or verified Hoover customers.

## Artistic assumptions and runtime

Reveal timing depends on distance from Hoover, not electrical connectivity or travel time. Particle direction, speed, brightness, quantity, and trails are artistic. A segment may point visually away from Hoover without connecting to it. The animation does not trace contracted deliveries, model alternating current, measure power, or imply that Hoover powers every displayed corridor or city. Public transmission layers can contain positional errors, omissions, and obsolete statuses.

MapLibre GL JS 5.6.0 renders local GeoJSON in Web Mercator. A custom WebGL2 layer provides additive cyan glows and continuous fading ribbons (20 connected sections per streak), interpolated along the existing route samples; blurred geographic lines provide a bloom-like effect. The camera starts over Hoover Dam and eases outward to the existing Southwest extent over 10 seconds. It then stays stationary; manual pan/zoom interrupts the pullback. Streak speed is set to 20× the pre-speedup setting (50× the original soft-line speed) for presentation, not an electrical travel-time estimate. Hoover illuminates at 0.5–1 seconds, corridors at 1–4 seconds, and trails/cities at 2–3.5 seconds. The selected network settles by 4.5 seconds. Ribbon phase fades at route ends before restarting on that same geometry; it never connects unrelated features. The complete grid remains faint, only the 261 sampled corridors get the brighter cyan layer, and Hoover retains the strongest halo. Reduced motion disables movement. All runtime assets are local and compatible with static hosting. Vendor licensing is in `vendor/LICENSE.txt`.

`data/sources.json` records retrieval, filtering counts, source dates, service terms, and SHA-256 hashes. Raw source caches remain outside Git. Attribution remains visible in the page footer and map attribution control.

The Colorado River uses Natural Earth’s [1:50m rivers and lake centerlines](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_rivers_lake_centerlines.geojson), retrieved November 11, 2026 under the same public-domain terms. Only named Colorado features intersecting the study region are selected, retaining whole geometry. This is generalized geographic context, not a surveyed channel or current water extent. Lake Mead and river styling remain distinct from cyan transmission corridors.
