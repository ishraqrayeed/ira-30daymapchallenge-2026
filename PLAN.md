# Project plan

See [the original project plan](30DayMapChallenge_2026_CODEX_PLAN.md).

The supplied daily themes are retained as planned; independent verification against the official 2026 announcement is pending.

## Accepted scope updates

- Day 1: restrict to pedestrian- or bicycle-involved crashes (inclusive OR),
  retaining the fatal/serious-injury focus. Count each incident once and report
  mode overlap. Use crash-level severity language, not person-level injury claims.

- Day 1 period: 2021–2025, five complete calendar years. Severity includes
  positive counts OR explicit fatal/SBI offense labels, following the coverage
  audit. Include annual counts alongside the combined map.

- Digital map output: interactive HTML is primary. The user will capture browser
  screenshots for social media; remove the separate PNG export requirement.
- Day 1 presentation: responsive sidebar, muted OSM basemap, severity point
  hierarchy, occurrence timestamp, and optional reported crash context.
- Hosting direction: GitHub Pages, once a repository is connected and publication
  is requested. No deployment has been performed.

- Latest presentation direction: full-screen map; headline, severity legend, and
  source credits only. Keep explanatory text and AI disclosure in documentation.
